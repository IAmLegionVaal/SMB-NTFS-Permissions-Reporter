# SMB NTFS Reporter

A read-only PowerShell toolkit for Windows storage and SMB reporting.

## Features

- SMB share inventory
- Local folder metadata export
- Storage review checklist
- CSV, JSON, and HTML reports

## How to run

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\SMB_NTFS_Permissions_Reporter.ps1
```

## Safety

Diagnostic-only. It reports storage context for support review.
